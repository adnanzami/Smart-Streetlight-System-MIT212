## Project Description
Develop a Smart Streetlight Management System to support energy efficiency and sustainable urban infrastructure, aligned with SDG 11 (Sustainable Cities and Communities) and SDG 7 (Affordable and Clean Energy).

The system manages streetlight assets, operational status, energy usage, and maintenance records. Its objective is to improve energy efficiency, enable timely maintenance, and support data driven optimisation of public lighting systems.

Students must implement two separate versions of the same system using MongoDB and Redis independently, enabling a comparative evaluation of document oriented and key value database technologies.

## Project Features
Users (e.g. city infrastructure managers) can:
*	Register streetlights with location, type, power rating, and zone
*	View the operational status of all streetlights (on/off/faulty)
*	Update streetlight details and status information
*	Record maintenance activities and fault reports
*	Track energy usage by streetlight or zone
*	Identify malfunctioning or high consumption streetlights
*	Remove decommissioned streetlights from the system
